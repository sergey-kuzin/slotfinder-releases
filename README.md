# Slotfinder для macOS

Подбор времени встречи по календарям Exchange коллег, выбор свободной переговорки
и отправка приглашения. Требуется macOS 26 и учётная запись Exchange Авито.

## Установка

1. Скачайте свежий DMG в разделе **Releases** справа.
2. Откройте DMG и перетащите Slotfinder в «Программы».
3. При первом запуске введите доменный логин `avito\логин` и корпоративный пароль.

Приложение обновляется само: при появлении новой версии предложит установить её.
